# MDL CSS Powerhouse

This example tests how much MDL can hand to CSS without JavaScript.

It uses:

- `:has()` for theme and density state
- `@container` for component-level responsiveness
- `@layer` for CSS ordering
- `@property` for typed animation
- CSS functions such as `clamp()`, `calc()`, and `color-mix()`
- Native `details` / `summary` disclosure

Run it:

```bash
../../bin/mdl serve
```
