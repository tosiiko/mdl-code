# MDL Complete Website

A complete multi-page website authored in MDL. It includes a home page, docs,
CLI commands, examples, pricing, a contact page, bundled CSS, a JavaScript
module, and a generated hero asset.

Run it from this folder:

```bash
../../bin/mdl serve
```

Build static output:

```bash
../../bin/mdl build
cp -R assets dist/assets
```

Open the local preview at:

```text
http://127.0.0.1:4001
```
